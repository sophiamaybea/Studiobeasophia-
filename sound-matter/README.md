# Sound Matter

An audio-reactive visual identity engine for Studio Bea Sophia.

- Analyses music locally in the browser with the Web Audio API.
- Maps frequency bands, RMS energy, spectral centroid, spectral spread and spectral flux/onsets into spring-mass ribbons, paint events, particulate marks and persistent surface memory.
- Supports local audio files, microphone input, pointer interaction and embed mode.
- No external runtime or copied artwork.

Embed mode:

`/?embed=1&src=https://example.com/song.mp3&title=Track%20Name`

Remote audio must permit CORS.
